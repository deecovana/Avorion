## Delete FarAway lost ships (rus)
Как удалить потерянные за барьером корабли удаленно:
  1. Откройте Меню игрока (клавиша I по умолчанию).
  2. Перейдите на вкладку «Флот» (Fleet), где отображается список всех ваших судов.
  3. Выберите в списке тот корабль, который остался за барьером.
  4. В правой части экрана нажмите кнопку «Удалить» (Delete) или «Списать» (Abandon).
    - Если корабль отображается как уничтоженный (иконка обломков), в этом же меню флота 
    нажмите кнопку «Удалить обломки» (Delete Wreckage). Слот мгновенно освободится.
    - Обратите внимание: при удалении через меню флота ресурсы за сам корабль не возвращаются, 
    но это единственный способ избавиться от него на огромном расстоянии.
